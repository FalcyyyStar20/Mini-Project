Experiment 6: Angular Framework

AngularJS "Hello World" Project

Two-Way Bound Expressions:

Hello World Greeting: Hello, {{ studentName || 'Operative' }}!

Uppercase Expression: {{ (studentName || 'Operative') | uppercase }}

Status: {{ customMessage }}

Arithmetic Evaluation: {{ 6 * 7 }} (Evaluated expression {{ 6 * 7 }} = 42)

AngularJS Script (ng-controller):
var app = angular.module('HelloWorldApp', []);
app.controller('HelloWorldController', function($scope) {
  $scope.studentName = 'Alex Chen';
  $scope.customMessage = 'AngularJS two-way data binding active!';
});
